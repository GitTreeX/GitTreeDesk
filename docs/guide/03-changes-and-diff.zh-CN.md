# 03 · 变更与 Diff

> 状态：✅ 已实现 · 范围：v1 · 工程参考：[`../spec.md`](../spec.md)

**Source Control 视图**（活动栏）就是多仓库变更列表：每个仓库一节，全部未提交工作一目了然。

## 哪些仓库会出现

- 仓库有变更、**且**在 Repos 视图的逐仓库勾选中被选中时出现（第 01 页）。仓库有 50+ 时，这能让视图聚焦于手头正在处理的仓库。
- 工具栏操作："仅显示所选仓库"开关、"全选 / 全不选"。
- 有进行中操作（merge、rebase……）的仓库始终出现，其分节顶部显示操作横幅：**Continue / Skip / Abort** 以及冲突文件列表（详见第 06 页）。

## 分组与开关

每个仓库分节把变更归为 **Staged（已暂存）**、**Unstaged（未暂存）**、**Untracked（未跟踪）**、**Conflicts（冲突）** 四组。每组都可在视图选项中隐藏——例如很少提交新文件时可以关掉 *Untracked*。

每个分节底部是**提交框**（消息输入、✨ 生成按钮、Commit / Amend / Stage-all——详见第 04 页）。

## 文件行操作

状态字母：`M` 修改 · `A` 新增 · `D` 删除 · `R` 重命名 · `U` 未跟踪 · `!` 未合并/冲突 · `C` 复制。

- 悬停操作：**Stage** / **Unstage** / **Discard**。支持多选（Shift/Ctrl+点击），操作作用于整个选中集合。
- **目录粒度**：暂存一个文件夹即暂存其下全部内容。
- **Hunk 级暂存**——在 diff 视图中，每个 hunk 边栏有操作：暂存该 hunk（未暂存文件）或取消暂存该 hunk（已暂存文件）。行级暂存为 [Later]。
- **加入 .gitignore**——未跟踪行可用；模式追加到 `.gitignore` 并立即暂存。
- `Space` 暂存/取消暂存选中行；`Enter` 打开 diff。

## Discard 的语义（重要）

| 情况 | 行为 |
|---|---|
| 已修改 / 重命名文件 | 从 index 恢复。**不可逆**——确认对话框会明确说明将丢失什么。 |
| 未跟踪文件 | 文件被**移入系统回收站**——可从回收站找回，无需恐吓式对话框。 |
| 冲突文件 | 不可 discard；先解决冲突（第 06 页）。 |

## Diff 视图

点击变更文件会在编辑区打开 diff 标签。

- **布局**：并排 ⇄ 内联切换。**忽略空白**开关。自动换行遵守编辑器设置。
- 重命名显示 旧路径 → 新路径 及内容 diff。二进制文件显示体积信息；图片显示**前后 2-up 预览**（洋葱皮滑块为 [Later]）。
- 边栏操作：**暂存 hunk / 还原 hunk**；右键菜单可复制 patch。
- **与…对比**——切换文件的对比基线：`INDEX`、`HEAD`、任意 ref / 分支。同一选择器也支持**整个仓库范围**（把工作树与某 ref 对比），入口在仓库右键菜单。单仓库内的目录级对比为 [Later]。

## 文件历史

- diff 标签工具栏有 **History** 开关：列出触碰过该文件的提交列表；点击某提交打开该文件在该版本的 diff。
- rename 跟随为 [Later]。

## 边界情况

- **未跟踪文件数量病态**：Untracked 组只列带上限的一批并给"显示更多…"，不会把视图卡死。
- **超大 diff**：超出体积上限的文本 diff 打开时附"仍要加载完整 diff"操作；二进制与 >10 MB 文件遵循编辑器规则（第 10 页）。
- **打开期间的磁盘外部变更**：标签标记为过期并提供重新加载。
- **CRLF / .gitattributes**：diff 按 Git 产出的原始内容展示——GitTreeDesk 永不自行归一化行尾。忽略空白开关可缓解；行尾混用时悬停显示检测结果。

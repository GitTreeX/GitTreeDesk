# 09 · 提交图

> 状态：✅ 已实现 · 范围：v1 · 工程参考：[`../spec.md`](../spec.md)

## 打开

- **每个仓库一个提交图标签**（标题形如 `<仓库名> (Graph)`）：从**活动栏的提交图按钮**（作用于当前仓库）、命令面板（"打开提交图"）或仓库行右键菜单（"打开提交图"）打开。最多约 5 个图标签同时存活（LRU）；重新打开瞬时完成。
- 提交图默认覆盖全部 ref：本地分支、远端分支、tag 与 HEAD。

## 你会看到

- 带泳道的提交行，按开发线着色；ref 标签（`HEAD`、分支名、`origin/…`、tag）挂在它们指向的提交上。
- 每行的 subject、作者、相对时间。
- 相对当前分支 upstream 的 **incoming / outgoing 标记**——哪些提交尚未推送、哪些尚未拉取。
- 当前分支的顶点高亮；点击任意行打开**详情面板**（右侧）：完整 message、作者与提交者的时间戳、带逐文件统计的变更文件列表。点击文件在编辑区打开该提交对该文件的 diff。

## 加载行为与规模

- 首页加载 1 000 个提交；向下滚动按 2 000 条分块流入更早历史——提交图绝不等待全量历史。
- 超大仓库启用"超大仓库模式"限制已加载窗口（窗口化查询 + 总数），并在工具栏说明；[Later] 提供调大窗口的设置。
- 性能目标：已加载 5 000+ 行时滚动顺滑（60 fps）；1 万提交仓库首帧约 1.5 秒内。

## 过滤

工具栏过滤器（可组合）：ref 多选（分支/远端/tag）、作者、路径、日期区间、消息文本搜索，以及**"仅当前分支可达"**（隐藏无关历史）。过滤状态按标签保存并记忆。

## 提交上的操作

右键任意提交（或使用详情面板）：

| 操作 | 说明 |
|---|---|
| 检出该提交 | detached HEAD，附"在此创建分支"横幅 |
| 在此创建分支 / 创建 tag | 选择器对话框 |
| Cherry-pick / Revert | 带 `--no-commit` 选项（第 06 页） |
| 把当前分支重置到此处 | soft / mixed / hard（第 06 页） |
| 把当前分支 rebase 到该提交 | |
| 自此交互式 rebase | 列表编辑器（第 06 页） |
| **编辑提交…** | 改写 message / 作者 / 时间，带备份与撤销（第 04 页） |
| 复制 SHA / 复制 ref 名 | |
| 选择用于对比 | 再右键另一提交 → "与所选对比"——两个提交间的 diff 在编辑区打开 |

## 键盘

- `↑` / `↓` 逐行移动，`Enter` 打开详情，`Esc` 关闭详情面板。
- `Ctrl/Cmd+F` 聚焦过滤栏；输入即实时过滤消息。

## 边界情况

- Detached HEAD：图中以 chip 显示游离位置；仅限分支的操作隐藏。
- reflog 条目（无任何 ref 可达的提交）v1 不展示。[Later]
- 历史改写（amend / rebase / 编辑提交）后图自动刷新。改写前的状态仍可通过 backup ref 找回——它们**不会**作为普通 ref 出现在图中；入口是"从备份恢复…"（第 06 页）。
